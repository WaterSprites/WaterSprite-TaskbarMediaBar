# WaterSprite TaskbarMediaBar 试用版 0.6.17

完整解压后运行 `WaterSprite TaskbarMediaBar.exe`，保留同目录资源。无需另装 Node.js 或 Python，需要 Windows PowerShell 5.1。普通压缩包名为 `WaterSprite-TaskbarMediaBar.zip`。GitHub 发布准备包名为 `@WaterSprites-TaskbarMediaBar-SoftMist-BlackSheerTights.zip`。

## 目录与浏览器插件

本体放在 `WaterSprite TaskbarMediaBar`；安装包和源码放在同级的 `任务栏播放器 WaterSprite TaskbarMediaBar 安装包`，说明书放在 `任务栏播放器 WaterSprite TaskbarMediaBar 设置`。

Chrome 扩展管理页开启开发者模式，点击“加载已解压的扩展程序”，选择安装包文件夹里的 `浏览器插件`。迁移后先加载新位置，再移除原来同名插件，避免重复控制。

运行设置与浏览器配对信息保存在同级的 `WaterSprite TaskbarMediaBar\用户配置`，首次启动继承旧版设置。缓存默认保存在同级的 `WaterSprite TaskbarMediaBar\缓存`，分别建立界面缓存、临时文件、运行数据、日志、崩溃记录子文件夹。网页图片目前为内存缓存，不写图片文件。右键 → 设置 → 缓存位置，可选择文件夹、打开当前文件夹、恢复默认位置；修改后播放器自动重启生效，保留主题、位置和浏览器配对。已有缓存会迁移到新位置，核对成功后清理旧缓存；无关文件保留，用户配置不移动。浅色背景为白色 RGB(255,255,255)、32% 不透明度，增加白色底色；深色背景为 RGB(32,32,32)、60% 不透明度，使悬浮深色模式明显加深；停靠背景透明，沿用任务栏自身的模糊效果。悬浮窗口目前未接入任务栏的 XAML 模糊层，背景着色一致，模糊效果不作相同承诺。

## 固定布局与启动

- 启动后默认停靠任务栏；已有停靠记录时恢复屏幕和左右位置，否则使用主屏左端。检测到任务栏后才显示窗口。
- 没有媒体时第一行显示 WaterSprite，第二行显示柔雾黑丝，不显示连接提示。
- 歌名固定第一行，歌词固定第二行。无歌词时第二行留空，不让歌名居中。
- 暂停保留当前歌名、封面、歌词与最后有效进度，不因出现别的空闲媒体会话而切换歌曲。
- 无封面时保留空白封面位，不显示音符占位图，文字和按钮不左右移动。
- 播放器文字、封面、按钮、拖动区域和托盘图标不弹出鼠标悬停说明，按钮保留无障碍名称。
- 播放按钮固定在文字右侧；长歌名和歌词在各自范围内滚动。
- 右侧停靠位于托盘区左侧。播放器底边靠近任务栏上沿 32 个界面单位内才进入吸附范围，仅松手时吸附。提示使用半透明灰色渐变、虚线边框和“将播控移动到此处”。
- 各屏幕吸附框提前准备，由独立辅助进程在原生拖动过程中显示，避免等待界面创建而丢失提示。
- 拖动手柄由 Windows 原生移动窗口，拖动途中不重建窗口；跨屏按各屏缩放显示，保持封面、文字和按钮完整。
- 每块屏幕分别读取托盘及 XAML 时钟边界，无法读取时按缩放后的保留区域避让；跨缩放后校正实际宽度和可见区域，避免覆盖副屏托盘。
- 托盘图标使用透明底黑白音乐符号。生产程序固定使用同一数据目录和托盘标识；正常退出时删除图标。开发检查不创建托盘图标。

汽水音乐：只读 `%APPDATA%\SodaMusic\LunaCacheV2\entries.db` 中缓存的歌曲和歌词，后台匹配当前歌名、歌手、时长。

酷我音乐：从真实播放窗口标题读取歌名、歌手，自动匹配 `A:\Apps\播放器\酷我音乐\酷我音乐 缓存\歌词` 中的 LRC，支持 UTF-8 和 GB18030。通过 Windows 文字识别读取窗口底部真实时间，没有读到可靠进度时不显示同步歌词。已验证《青衣（可楼DJ版）》04:16 / 05:19 时显示正确歌词。窗口最小化、换肤或底部样式改变可能导致进度读取失败。该缓存目录的 19 个 MP3 未包含嵌入封面，独立图片缓存尚未接通。

Apple Music：读取系统“音乐”文件夹下 Apple Music 资料库记录的各首歌实际路径，支持歌曲分散在不同文件夹。按歌名、歌手、时长匹配后读取文件嵌入封面；兼容系统媒体信息把歌手和专辑合并成“歌手 — 专辑”的情况。当前资料库五首歌已匹配，四首带有封面，《Watch me move》文件没有嵌入封面。不修改资料库和音频文件。

网易云音乐：增强连接已验证当前客户端的真实暂停／恢复、播放进度与逐句歌词读取。通过歌曲 ID 读取网易云官方封面；未开启增强连接时，仍从真实窗口标题识别歌曲，并严格匹配官方数据。没有可靠进度时不显示同步歌词；没有逐句歌词的歌曲留空。

歌曲未缓存、匹配存在歧义或没有可靠歌词时留空，不提供手动加载歌词。缓存稍后生成会重试；没有封面时维持固定布局。

## 操作与控制范围

自动选择跟随最近开始播放或切换视频的来源，不再让旧音乐或直播长期压住新网页；同时出现时优先当前前台软件，再按音乐、桌面视频／直播、网页排列。所有来源安静时保留上一次信息。音量峰值采用短暂容错，避免歌曲短暂静音时反复切源。右键手动选择来源会固定该来源，选择“自动选择”恢复自动切换。

封面禁止拖出图片；悬停显示跳转图标，点击恢复并打开当前音源的软件窗口。不移动封面、文字或按钮位置。播放命令保留期望状态，避免旧状态导致图标闪动；等待确认期间仍可再次点击，连续操作按最后一次点击执行。媒体来源菜单勾选当前实际音源，点击“自动选择”恢复自动选择。

## 浏览器控制插件

浏览器控制插件名称统一为“任务栏播放器 WaterSprite TaskbarMediaBar”。真正暂停未提供系统媒体接口的直播网页，需要安装配套扩展。播放器启动后在你指定的 `任务栏播放器 WaterSprite TaskbarMediaBar 安装包\浏览器插件` 生成配对文件。Chrome 打开扩展管理页，开启开发者模式，选择“加载已解压的扩展程序”并选择此目录，然后刷新直播页面。插件更新后需在 Chrome 扩展管理页点一次重新加载，再刷新直播页面。不要修改配对文件 auth.js。

扩展覆盖 HTTP/HTTPS 网页，仅在发现音视频元素时向本机发送页面标题、网址、图标和播放状态。普通网页视频优先沿用系统播控，直播或缺少系统播控时使用页面 pause/play。网页第一行显示平台名，第二行显示页面标题或副标题，音乐音源保留原有歌词位置。

直接调用页面音视频元素的 pause/play，不改变音量。网页脚本通过插件后台连接本机 127.0.0.1:43829，避免网页跨域限制；连接校验随机配对令牌。配对文件每台电脑自动生成，不放入发布压缩包。播放器退出后本机服务关闭。抖音直播的实际暂停、恢复和网站图标读取已验证；其他直播网站尚未逐站验证。网页封面禁止沿用系统提供的浏览器图标；优先读取媒体封面、海报、缩略图和作者头像，缺失时尝试网站图标；网页没有可用图片时显示本软件的透明底音乐图标，图标不透明度为 62%，随主题切换黑白颜色；音乐软件没有封面时仍保留空白位置。直播客户端独立 APP 的专用暂停接口尚未接通；已有系统媒体接口时仍使用该接口。

左侧竖线用于拖动，可停靠任意屏幕任务栏的左端或右端；右键“设置 → 多显示器”也可选择位置。小叉隐藏窗口，点击托盘图标显示，右键退出。主题默认跟随系统，保留手动深色、浅色；开机启动默认开启，可从右键关闭。

“自动选择”按前述实际输出和优先级规则自动切换；仅打开空闲软件不切源。媒体来源列出实际媒体会话、活动音频会话，以及识别到真实窗口的酷我和网易云，不列已安装软件清单；过滤 NVIDIA 的 nvcontainer 等辅助进程。

中间按钮仅显示播放、暂停，操作不改变音源音量。提供系统媒体会话的应用使用真实播放、暂停、上一首、下一首命令，兼容仅提供单独播放/暂停命令的应用。酷我当前标准皮肤已验证点击底部播放控件可真正暂停并恢复声音；非标准皮肤或小窗模式需要复测，默认快捷键只作为后备路径。网易云增强连接使用客户端当前歌曲与播放接口，已验证定向暂停和恢复；上一首、下一首使用客户端对应按钮，尚未实际切歌验证。红心收藏尚未接通，不展示。

MPC-HC：已验证当前版本可以直接提供系统媒体会话、歌曲信息和封面。有系统媒体会话时直接使用；旧版专用适配仍需在 MPC-HC 中启用本机 Web 接口 `127.0.0.1:13579`，真实视频封面尚未完整验证。

## 常驻、图标与菜单

睡眠和休眠使用唤醒事件重新连接媒体与任务栏桥接；解锁、显示器变化和长时间空闲后重新操作，也会检查窗口位置与显示状态。渲染窗口重新加载后会恢复显示，桥接进程意外退出会自动重建。用户主动隐藏仍保持隐藏。恢复记录保存在所选缓存目录的“日志”子文件夹。

EXE 使用透明底白色音乐符号、倾斜椭圆深色光晕和非常轻微的柔和阴影；托盘图标随播放器主题使用深色或白色光晕。右键菜单保留主菜单，悬停或点击带箭头的项目在旁边展开子菜单；空间不足时在左侧展开。方向键可以选择或展开项目，Esc 关闭。深色菜单使用较浅的柔雾玻璃着色，浅色菜单保持原效果。无音源时封面位置显示本软件图标。打开缓存文件夹使用独立的 Windows 原生文件视图，不显示导航栏，不改变其他资源管理器窗口的设置。

MPC-HC 播放本地音乐时读取当前文件的内嵌封面，文件没有内嵌封面时显示无封面状态。音乐不使用播放器窗口的上一帧截图。

GitHub 安装包名称为 `@WaterSprites-TaskbarMediaBar.zip`，放在安装包目录的 `GitHub - @WaterSprites - WaterSprite-TaskbarMediaBar` 子文件夹。普通安装包仍为 `WaterSprite-TaskbarMediaBar.zip`。

主菜单为媒体来源、设置、退出；设置包含开机启动、缓存位置、外观和多显示器。菜单采用较窄的宽度和较紧凑的行距。

托盘右键菜单以右键点击位置为锚点，在点击位置上方弹出；创建窗口时直接使用目标屏幕的位置，避免混合 DPI 屏幕间移动窗口导致定位偏移。菜单保持在托盘弹层上方。

多显示器菜单每次打开读取当前启用的显示器，屏幕编号后显示 Windows 提供的显示器名称；显示器数量不限制为四台，断开后不再列出。左端、右端停靠根据实际任务栏按钮占用区域寻找空位，避开开始、搜索、应用按钮和托盘。居中布局保留左边空位；左对齐布局避开左侧按钮。布局切换或无足够空位时临时悬浮，空位恢复后回到所选端；用户手动拖动后保持用户选择。无音源时“柔雾黑丝”与“WaterSprite”使用相同文字颜色。

右键菜单取消开关动画及悬停展开延迟，使用透明窗口和圆角裁剪显示背景，避免系统背景层露出方角。无封面的网页、微信视频号等音源统一使用最终确认的软件图标；窗口图标与托盘图标跟随浅深主题。

右键主菜单和多级子菜单在启动时预加载，关闭后隐藏并复用窗口。右键弹出不再等待重新创建窗口或捕获背景，显示路径中的文件写入和焦点操作移至显示之后执行。

菜单弹出路径取消同步状态写入，模糊背景由系统实时合成，窗口保持禁用系统过渡动画；保持直接显示和直接关闭。

菜单不会因为短暂焦点切换而自行关闭；仅选择操作、点击菜单外或按 Esc 时关闭。菜单属于播放器，主菜单弹出时接收焦点，悬停展开的子菜单保持不激活直到点击，关闭时不会重复显示已可见的播放器，减少 Dock 的窗口提示闪动。

音源退出后清空歌名、歌词、封面和播放控制，恢复 WaterSprite／柔雾黑丝；仍存在的暂停音源继续保留当前歌曲。自动选择不会继续跟随已退出的播放器。已退出的已知音乐播放器从 Windows 可能滞留的媒体会话中排除。

打开开始菜单或搜索时，播放器保留任务栏位置且不会主动隐藏。任务栏信息短暂缺失时保留最近有效的停靠位置；只有持续缺少可用停靠位置或显示器断开，才进入悬浮回退。

浏览器插件 1.1.13 优先从当前播放的视频所在卡片读取信息流文案和作者，支持 X、微博、抖音、快手的对应页面规则。静音视频也参与可见性选择。封面优先使用当前视频的缩略图，不遍历其他视频；图片并行返回，优先级更高的图片完成后替换回退图标。更新插件后需在 Chrome 扩展管理页重新加载并刷新网页。

## 自动客户端接入

### YY 桌面 APP

播放器自动发现 YY 主进程已有的本机读取端口，从娱乐模板页面取得当前频道编号，再读取该频道的公开直播名称和官方直播画面缩略图。上行显示“YY”，下行显示直播名称；图片采用直播画面，避免用主播头像替代。换频道时清除旧结果，旧请求不能覆盖新频道。

本机 YY 9.59.0.0 的两个频道已完成读取验证，不需要重启 YY、修改快捷方式或添加启动参数。若其他版本没有提供该本机接口，或公开页面/图片接口不可用，不能保证名称和图片可读取。频道不唯一时不猜测对应关系。保留现有播放控制和三类自动优先级。

### 斗鱼桌面 APP

斗鱼客户端的音频来源识别为斗鱼时，播放器从本机 `%LOCALAPPDATA%\DouyuLive\logs\PCClient` 中的近期播放日志读取房间编号，仅采用播放器/解码器的房间记录，忽略推荐和聊天记录。根据编号读取斗鱼公开房间信息及真实直播缩略图，上行显示“斗鱼”，下行显示房间名称，长名称沿用现有文字移动效果。

此方式不需要修改斗鱼启动入口或重启客户端。房间切换后清除旧房间结果，旧请求返回不能覆盖新房间；网络失败或没有可用日志时不能保证名称和封面可用。已用本机斗鱼 9.2.4.0 的两个房间验证读取，其他版本日志结构变化仍需适配。保留原有播放控制和第一类 > 第二类 > 第三类的自动优先级。

### Instagram 浏览器视频

浏览器插件 1.1.17 增加 Instagram 当前帖子和 Reels 文案读取：优先读取当前视频所在帖子的文案；Reels 从最近的单视频容器读取文字块，排除作者头像、评论和邻近帖子的图片。帖子没有文案但可取得作者时显示“作者 · 视频”；没有可读取的封面图时，尝试用当前视频画面作为封面回退。网站的跨域限制可能阻止画面读取，不能保证所有页面都能取得图片。更新后需在浏览器扩展管理页重新加载本插件，并刷新 Instagram 页面；首页、个人主页及 Reels 的实际显示仍需分别验证。

当前网易云歌词增强读取依赖网易云启动时开启本机连接接口。启动参数如下：

```text
--remote-debugging-address=127.0.0.1 --remote-debugging-port=43831
```

使用 Windows 快捷方式时，右键快捷方式 → 属性 → 快捷方式，在“目标”中把参数放在程序路径的结束引号后面，中间留一个空格。例如本机的完整目标为：

```text
"A:\Apps\播放器\网易云音乐\CloudMusic\cloudmusic.exe" --remote-debugging-address=127.0.0.1 --remote-debugging-port=43831
```

其他电脑应换成实际的网易云安装路径，不能直接照搬上述 A 盘路径。参数不能写在路径的引号里面，也不用修改程序文件名。

使用罗技 Options+ 的 Actions Ring 或其他启动器时，程序路径仍选择 `cloudmusic.exe`，把上述两项填写到该动作的启动参数栏。不同入口各有自己的参数；只修改一个快捷方式不会让其他启动入口自动带上参数。开始菜单入口需要修改它实际指向的快捷方式。

保存后，先彻底退出网易云，包括托盘中的网易云，再从已配置的入口重新打开并播放歌曲。已经运行的网易云不会因为再次点击带参数的入口而必然开启接口。WaterSprite TaskbarMediaBar 会自动检测本机接口，不需要手动连接；不需要打开桌面歌词。

本机已验证网易云 `3.1.36.205322`：普通歌曲《丢了你／井胧》的歌词能够显示并与播放句子同步；已配置的开始菜单入口重启验证通过，操作环的两处启动动作也已补充参数。VIP 试听歌词尚未完成验证，不能视为已支持。其他版本或未带参数的启动入口尚不能保证歌词增强读取正常；本方法是有条件的本地适配，并非所有电脑、所有启动方式都已自动兼容。

接口仅用于本机读取。保留 `127.0.0.1`，不要改成对外监听地址。上述设置主要影响歌词增强读取及其播放进度；歌名、封面是否可用还取决于其他已有读取来源，不能据此认定没有参数就一定无法显示歌名或封面。

已移除手动“客户端连接”菜单。网易云和哔哩哔哩现有快捷方式使用仅监听本机的连接参数，播放器在后台自动检测接口；原快捷方式保存在配置文件目录的“客户端启动备份”。不修改账号、音量和播放快捷键。已验证从本机常用集合快捷方式正常启动时接口自动开启。直接运行第三方 EXE 或使用尚未配置的其他启动路径，不在这次验证范围内。

桌面哔哩哔哩视频已验证读取当前视频名称、真实封面和进度，并定向暂停／恢复。直播使用独立播放接口及公开房间信息，本机直播名称和封面已核对正常；增强读取仍依赖带本机参数启动。斗鱼桌面 APP 的名称和封面使用上述本地播放日志适配，YY 使用现有本机频道接口和公开直播信息，播放控制沿用原有方式。抖音桌面 APP 已排除，不参与自动选源，也不出现在媒体来源菜单；网页抖音仍通过浏览器插件接入。

配套浏览器插件识别到的播放页，会以“快手（Chrome）”等平台名出现在媒体来源菜单。即使网页没有 Windows 媒体会话，也能手动选择并通过插件控制当前视频。自动选择时，同时播放的来源按第一类音乐及本地媒体播放器、第二类浏览器、第三类桌面视频与直播软件的顺序选择；低优先级来源不会因为后来开始播放而抢走显示。同一类内部优先最近开始播放的来源；同时开始时优先当前前台软件。手动指定来源不受自动选择覆盖。网页关闭或插件断开后，不保留失效封面和按钮。

右键菜单不再保存或铺设桌面截图，关闭窗口、托盘面板或切换背景后，不应残留之前的桌面画面。菜单仍复用窗口，保持直接打开／关闭和系统圆角；主菜单接收焦点，以保证托盘菜单按钮可点击。
