# WaterSprite TaskbarMediaBar 1.0.0

[查看说明书](https://github.com/WaterSprites/WaterSprite-TaskbarMediaBar)

主程序包：WaterSprite-TaskbarMediaBar-1.0.0-x64.zip。
浏览器插件包：WaterSprite-TaskbarMediaBar-Extension-1.1.18-Chrome.zip 或 WaterSprite-TaskbarMediaBar-Extension-1.1.18-Edge.zip。

两个 ZIP 直接解压到同一位置，合并 WaterSprite TaskbarMediaBar 文件夹；插件位于主程序内的“浏览器插件”。先启动主程序，再在浏览器加载该目录。

更新插件：新版 ZIP 覆盖原位置，保留 auth.js → 浏览器重新加载 → 刷新网页。
