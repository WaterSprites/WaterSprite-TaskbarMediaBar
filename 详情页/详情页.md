# 任务栏播放器 WaterSprite TaskbarMediaBar

在任务栏上查看正在播放的歌曲、封面与歌词，直接完成播放、暂停和切歌操作，减少来回切换播放器窗口。

支持浏览器查看和控制网页音视频。
支持浅色、深色外观切换。
支持多显示器使用。

@WaterSprites (水妖)

## 主要功能

| 功能 | 说明 |
|---|---|
| 媒体信息 | 显示当前歌曲名称、歌手及封面；网页媒体显示平台和页面内容信息 |
| 播放控制 | 在支持的来源上播放、暂停、上一首和下一首 |
| 同步歌词 | 为已适配的音乐来源读取歌词，随可靠的播放进度显示 |
| 自动选择来源 | 自动跟随活动媒体，也可以手动固定一个来源 |
| 打开播放来源 | 点击封面区域，打开对应播放器窗口或网页 |
| 位置调整 | 拖动任务栏播放器，或通过菜单选择显示器任务栏左端、右端 |
| 外观设置 | 跟随系统外观，也可以手动选择浅色或深色 |
| 托盘操作 | 隐藏后重新显示任务栏播放器、打开设置或退出程序 |
| 浏览器联动 | 配套插件连接本机任务栏播放器，提供网页媒体信息与播放控制 |

本软件是媒体信息显示与控制工具。音乐和视频仍由原播放器或网站播放，不替代原应用，也不提供音乐下载功能。



## 安装与首次启动

任务栏播放器：`WaterSprite-TaskbarMediaBar-1.0.0-x64.zip`。

Chrome 浏览器插件：`WaterSprite-TaskbarMediaBar-Extension-1.1.18-Chrome.zip`。

Edge 浏览器插件：`WaterSprite-TaskbarMediaBar-Extension-1.1.18-Edge.zip`。

按需下载、解压；只使用桌面音乐播放器时，无需安装浏览器插件。


### 使用环境

- Windows 11 x64 位程序。
- 保留 Windows PowerShell 5.1，用于程序的系统媒体与窗口桥接。
- 使用发布包运行，不需要另外安装 Node.js 或 Python。
- 程序所在位置需要允许当前用户写入设置与连接文件的权限。

### 启动任务栏播放器

1. 打开 `WaterSprite TaskbarMediaBar` 文件夹。
2. 运行 `WaterSprite TaskbarMediaBar.exe`。
3. 打开音乐播放器或网站，播放歌曲或视频。
4. 在任务栏查看媒体信息，使用播控按钮。

首次启动默认停靠任务栏；已有位置设置时恢复记录的位置。没有活动媒体时显示软件标识。

独立运行默认启用开机启动，可在 “设置 → 开机启动” 取消。移动整个程序目录后，应重新启动并检查开机启动设置。



## 浏览器扩展安装

只使用桌面音乐播放器时，可以先不安装浏览器插件。需要网页媒体信息和网页播放控制时，再安装配套插件。

### Chrome／Edge

1. 解压插件包，将“浏览器插件”文件夹放入任务栏播放器目录（与 WaterSprite TaskbarMediaBar.exe 同一层）。
2. 启动或重新启动 `WaterSprite TaskbarMediaBar.exe`。
3. 打开浏览器扩展管理页面：Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`。
4. 开启“开发者模式”。
5. 点击“加载未打包的扩展程序”（Chrome）或“加载解压缩的扩展”（Edge）。
6. 选择任务栏播放器内的 `浏览器插件` 文件夹（直接包含 `manifest.json` 的这一层）。
7. 刷新音视频网页，再开始播放。

不要在插件文件夹里选择单个文件，也不要把 ZIP 当作未打包插件直接加载。安装完成后保留插件文件夹，浏览器仍需从这里读取文件。

如果已经加载过旧位置的同名插件，完成迁移后只保留一份，避免重复发送媒体状态。

### 插件连接与权限

插件用于识别网页音视频、获取页面标题及可用封面，并执行受支持的播放控制，因此需要访问相关网页。插件与任务栏播放器通过本机连接通信；任务栏播放器退出后，这条本机连接也随之关闭。

`auth.js` 是任务栏播放器生成的本机连接文件。不要手动填写别人的令牌，也不要公开分享生成后的连接文件。插件 ZIP 不携带此文件，首次安装后由任务栏播放器生成；更新时保留原文件。

部分封面需要从原网站读取。网站页面结构、媒体接口、登录状态和播放限制都可能影响效果。



## 日常操作

| 操作 | 用法 |
|---|---|
| 播放／暂停 | 点击中间的播放或暂停按钮 |
| 上一首／下一首 | 点击两侧按钮，是否有效取决于当前来源是否支持切换 |
| 打开播放器或网页 | 点击封面区域，返回当前媒体来源 |
| 移动任务栏播放器 | 按住左侧拖动区域移动窗口 |
| 吸附到任务栏 | 拖动至对应任务栏左端或右端，出现位置提示后松开 |
| 打开菜单 | 在任务栏播放器上右键，或在托盘图标上右键 |
| 隐藏任务栏播放器 | 点击界面小叉；程序继续在后台运行 |
| 重新显示 | 点击系统托盘中的音符图标；若图标被折叠，先展开托盘区 |
| 完全退出 | 右键菜单选择“退出” |

暂停后保留当前媒体信息。



## 设置

### 外观

右键 → 设置 → 外观，可选择 “跟随系统” “深色” “浅色”。

任务栏播放器可手动选择浅色或深色；托盘图标跟随系统主题。

停靠和悬浮时的背景观感不同；最终效果也会受任务栏外观、壁纸、显示缩放和其他桌面美化工具影响。

### 多显示器与位置

右键 → 设置 → 多显示器，选择显示器，再选择“左端”或“右端”。

需要停靠副屏时，该屏幕上必须有横向任务栏。若程序提示没有检测到任务栏，请检查 Windows 的多显示器任务栏设置。也可以通过拖动让任务栏播放器处于悬浮位置。

### 开机启动

在“设置 → 开机启动”切换。通过 Windhawk 管理启动的运行方式会显示“由 Windhawk 启动”，应在对应管理工具中调整。

### 缓存位置

右键 → 设置 → 缓存位置，可以查看位置、打开文件夹、选择新文件夹或恢复默认位置。

更改后任务栏播放器会自动重启，将已有缓存迁到新位置，核对成功后清理旧缓存。缓存较大时请等待迁移完成。


### 版本与更新

点击“设置 → 更新”打开 GitHub 项目主页，查看版本与更新信息；使用新版本需下载替换。



## 播放器、歌词与封面

媒体信息、控制、歌词与封面是不同的能力。能够识别播放器，不代表它一定提供同步歌词或全部控制命令。

| 来源 | 适配方式与说明 |
|---|---|
| QQ音乐 | 媒体会话信息与本地歌词、封面适配；歌词和补充封面依赖缓存路径及歌曲匹配 |
| 汽水音乐 | 媒体会话信息与本地缓存歌词适配 |
| 酷我音乐 | 窗口信息、歌词和封面适配；皮肤、窗口状态及进度读取可能影响同步 |
| 酷狗音乐 | 歌词适配；可用结果取决于客户端状态和歌词数据 |
| 网易云音乐 | 媒体与增强连接适配，用于播放控制、进度和歌词读取 |
| Apple Music | 不支持在线音乐识别，仅支持本地资料库、音频文件封面适配 |
| MPC-HC | 专用控制及本地文件信息适配 |
| 哔哩哔哩、YY、斗鱼等客户端 | 已有相应适配代码；可用信息和控制能力随客户端状态、版本而变化 |
| Chrome／Edge 网页 | 系统媒体会话及配套插件；网页是否支持切换、暂停和封面取决于页面实现 |

抖音桌面客户端当前不作为支持来源。

歌曲未缓存、没有歌词、匹配有歧义或无法获得可靠时间时，歌词可能留空；当前不提供手动加载歌词功能。

QQ音乐歌词与封面、酷我歌词会根据播放器配置、安装位置及常见目录查找缓存。找不到缓存或歌曲尚未缓存时，对应内容可能留空。

增强连接会为部分客户端准备启动参数，并保存原快捷方式备份。卸载时如需恢复原客户端启动方式，应按备份核对恢复；不要无故删除这些备份。



## 更新、迁移与卸载

### 更新任务栏播放器

1. 从菜单完全退出任务栏播放器。
2. 备份原程序目录及需要保留的设置。
3. 更新完整的程序文件，不只替换 EXE；保留原 `用户配置` 和 `浏览器插件` 文件夹。
4. 保留原设置和配对信息，启动新版本，检查版本、位置及媒体显示。

首次运行会在任务栏播放器文件夹内分别创建 `用户配置` 和 `缓存`。
用户配置保存外观、位置、开机启动、浏览器连接信息和客户端启动备份；缓存保存运行数据。

默认用户配置位置为 `WaterSprite TaskbarMediaBar\用户配置`。
默认缓存位置为 `WaterSprite TaskbarMediaBar\缓存`。
自定义缓存后，以菜单显示的位置为准；用户配置独立保留，不随缓存位置变化。

### 更新浏览器扩展

1. 解压新版插件包，将其中的“浏览器插件”文件夹覆盖替换到任务栏播放器目录。
2. 在浏览器扩展管理页面点击该插件的“重新加载”。
3. 刷新音视频网页。

任务栏播放器不会覆盖独立插件的代码、图标或版本。插件没有变化时，无需为了任务栏播放器版本号更新插件。迁移到其他文件夹时，需要从新位置重新加载。

### 卸载

1. 关闭开机启动。
2. 从菜单完全退出播放器。
3. 在浏览器扩展管理页面移除插件。
4. 删除任务栏播放器与浏览器插件文件夹。

简单一句话，直接删就行。^_^



## 常见问题

### 启动后没有看到任务栏播放器

先查看托盘音符图标，点击它恢复显示。检查是否停靠在其他显示器，必要时通过设置菜单重新选择显示器和位置。小叉只隐藏窗口，不会退出程序。

### 浏览器扩展安装了，但网页没有显示

确认任务栏播放器正在运行，插件位于任务栏播放器内的 `浏览器插件` 文件夹，浏览器加载的是这一目录。先启动任务栏播放器，再重新加载插件、刷新网页并开始播放。不要同时加载多份同名插件。浏览器内部页面不属于普通音视频网页适配范围。

### 有歌名，没有歌词或封面

歌曲信息可以来自系统媒体会话，而歌词和补充封面依赖单独的适配及缓存。先确认对应来源的支持范围、缓存位置和当前歌曲的数据是否可用。

### 切歌按钮没有效果

当前来源可能只支持播放／暂停。部分网页和直播没有上一首、下一首功能，不能按普通音乐列表切换。可以反馈新增。

### 手动切换播放器

在“媒体来源”中手动选择希望控制的来源。手动选择的媒体来源关闭后，默认恢复“自动选择”，不会永久固定。
